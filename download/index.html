Pilot builds for Windows, macOS, and Linux. Python is bundled inside the app, and the first launch sets up the local engine and lab browser automatically.

Windows

64-bit (x64)

Extract the zip to a folder on your disk and run win-unpacked\pentagent.exe.

Windows portable archive (64-bit)

PentAgent-win-x64.zip.sha256

macOS

Apple Silicon (arm64)

Drag PentAgent to Applications. On first launch, right-click PentAgent and choose Open.
