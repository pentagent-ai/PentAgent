      Scanner

      Run a passive audit on captured traffic and review the issues it finds.

      Scanner looks through traffic you’ve already captured and flags possible issues. It doesn’t send new attacks on its own. Issues are identification leads. Confirmed findings with evidence show up under Records → Findings.

      Run a passive scan#

      1. Capture some traffic

        Browse your target in the lab window first.

      2. Start the scan

        Click New passive scan (or Run a passive scan when the list is empty). You can also start one from the Dashboard.

      While it runs, the status shows on the Dashboard. When it finishes, issues appear here. Tick Group by rule to group them. Open Dashboard jumps back to the live overview.

      Review an issue#

      Select an issue to see its severity, host and evidence. From there you can Open evidence in HTTP history, View transaction, View in Target / History, or Open in Records.

      Note

      Passive scans only look at what you’ve already captured. Queue AI leads (when enabled) sends candidates to Organizer under the Has AI lead filter.
