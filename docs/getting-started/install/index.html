      Install

      Download the pilot build, start it, and open PentAgent.

      What you need#

      • A 64-bit Linux computer. The pilot build is Linux only for now. Builds for macOS and Windows will follow.
      • Python 3.12 or newer, available as python3. Check with python3 --version.
      • An internet connection for the first launch, which downloads what PentAgent needs.
      • Pilot access. Anyone can download the build, but signing in needs an approved pilot account. If you haven’t applied yet, join the pilot.

      Download the pilot build#

      1. Open the download page

        Go to Download.

      2. Save both files

        You’ll get the app, pentagent-linux-x64.tar.gz, and a checksum file next to it, pentagent-linux-x64.tar.gz.sha256.

      3. Check the download (optional)

        In the folder where you saved both files, run:

        shell
        sha256sum -c pentagent-linux-x64.tar.gz.sha256

        You should see OK. If not, download the files again.

      Unpack and start PentAgent#

      Unpack the build anywhere you like, for example your home folder, then run the launcher:

      shell
      tar xzf pentagent-linux-x64.tar.gz
cd pentagent-*/
./pa_release/launch.sh

      The first launch takes a few minutes. It creates a private Python environment for PentAgent and installs everything it needs. You’ll see progress in the terminal. Later launches skip this and start in a few seconds.

      When it’s ready, PentAgent opens in your default browser at http://127.0.0.1:8765/. If the page doesn’t open on its own, copy that address into your browser.

      Note

      PentAgent runs only on your own computer. The address 127.0.0.1 means “this machine”, so nobody else on your network can reach it.

      Set up the lab browser#

      PentAgent captures traffic through a separate lab browser: its own Chromium window with its own profile, so your everyday browser is never involved. Install it once with:

      shell
      ~/.local/share/pentagent/venv/bin/python -m playwright install chromium

      This downloads a copy of Chromium just for PentAgent. It doesn’t change any browser you already use. If you already have Chromium installed from your Linux distribution, PentAgent can use that instead and you can skip this step.

      Everyday use#

      Starting PentAgent again#

      Open a terminal in the PentAgent folder and run ./pa_release/launch.sh. Always start it from inside that folder. Keep the terminal window open while you work.

      Stopping PentAgent#

      Go back to the terminal and press Ctrl+C. Close the PentAgent browser tab too.

      Launch options#

      Most people never need these. Set them in front of the launch command, for example:

      shell
      PENTAGENT_PORT=8800 ./pa_release/launch.sh
      Launch options
      SettingWhat it doesDefaultWhen to change
      PENTAGENT_PORTThe port PentAgent itself listens on. The app opens at this address.8765Another program on your computer already uses port 8765.
      PENTAGENT_DATAThe folder for PentAgent's Python environment and project database.~/.local/share/pentagentYou'd like PentAgent's data on a different disk or folder.

      Updating to a new build#

      1. Unpack the new build

        Download the new build and unpack it next to the old one.

      2. Refresh PentAgent's environment

        Remove the old Python environment so the new build can set up the parts it needs. Your projects are not stored there, so they’re safe.

        shell
        rm -rf ~/.local/share/pentagent/venv

      3. Start the new build

        Run ./pa_release/launch.sh from inside the new folder. The first launch sets things up again, then run the lab browser install once more.

      Your project database lives in ~/.local/share/pentagent, so your projects are there when the new version opens.

      Tip

      Keep the old folder until you’ve opened the new version and checked your projects.

      If PentAgent says Update required when you sign in, your build is older than the pilot supports. See Update required.

      Uninstalling#

      To remove PentAgent completely:

      1. Stop PentAgent.
      2. Delete the folder you unpacked.
      3. Delete ~/.local/share/pentagent. This removes the Python environment, your project database and the lab browser profile.
      4. If you installed the lab browser with the command above, delete its Chromium copy in ~/.cache/ms-playwright.
      5. If you trusted PentAgent’s certificate in another browser or tool, remove it there too. The certificate file itself lives in ~/.mitmproxy.

      If something doesn’t work#

      “python3: command not found” or a version error#

      Install Python 3.12 or newer from your distribution’s package manager, then run the launcher again. If the first launch stopped halfway, delete ~/.local/share/pentagent/venv and start again so it sets up from scratch.

      The page doesn’t load#

      Check the terminal for an error. If it mentions the address already being in use, another program has port 8765. Start PentAgent with a different port using PENTAGENT_PORT (see Launch options).
