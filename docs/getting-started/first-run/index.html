      First run

      Create a project, start the proxy, and capture your first request.

      Once you’re past the welcome screen, PentAgent opens its main window. This page walks through the window and gets your first request captured.

      The main window#

      1. 1Marker 1: Project picker. Switch between your projects here.
      2. 2Marker 2: New project field and its + button.
      3. 3Marker 3: The proxy button. It reads Proxy Off until you start capturing, and turns on once a project is open.
      4. 4Marker 4: The left menu, grouped into Workbench, Project and AI Agent.
      5. 5Marker 5: Your workspace, with the Proxy, Repeater, Intruder and Scanner tabs on top.
      6. 6Marker 6: Inspector, which shows params, cookies and headers for the message you select.
      7. 7Marker 7: AI Assistant, with Ask, Plan and Agent modes.
      8. 8Marker 8: The listener strip: whether the proxy is listening, plus Lab and Settings shortcuts.

      Create a project#

      A project keeps everything for one app together: its traffic, scope, findings and AI chats. Type a name in the New project field in the top bar and press Enter or click +.

      The new project opens straight away. Next, click the Target button next to the project name. It opens the Target tab, where you add your app’s host to the project’s scope. Until you do, the button reads No scope hosts.

      Get your first capture#

      With a project open, the Dashboard shows a short Get your first capture checklist. The next step to do is highlighted, and finished steps get a tick.

      1. Start proxy

        Click Start proxy. PentAgent starts a listener on 127.0.0.1:8088 that records the traffic passing through it. The step then reads Listening 127.0.0.1:8088.

      2. CA certificate

        To read HTTPS traffic, the browser needs to trust PentAgent’s certificate. PentAgent creates its local PentAgent CA certificate on your computer and the lab browser trusts it automatically, so usually there’s nothing to do here.

        Download CA saves the certificate as pentagent-ca-cert.crt. You only need it if you want to send traffic from another browser or tool through PentAgent yourself.

      3. Open lab browser

        Click Open lab browser. A separate Chromium window opens, already connected to the proxy. It has its own profile, so your everyday browser, its logins and its history are never involved. It starts on example.com.

      4. First capture

        In the lab window, go to the app you’re testing and click around. Each request appears in Proxy › HTTP history. Once the first one arrives, the checklist steps aside.

      Note

      Only test apps you own or have permission to test. A practice app running on your own computer, such as OWASP Juice Shop, is a good place to start.

      The same steps in the Proxy tab#

      You’ll find the same checklist, in a compact form, in Proxy › HTTP history while it’s still empty.

      The top bar#

      1. 1Marker 1: Project picker.
      2. 2Marker 2: Target shows your project’s scope host and opens the Target tab.
      3. 3Marker 3: Proxy button. Click it to start or stop the listener. It reads Proxy Active while capturing.
      4. 4Marker 4: Activity opens the Dashboard.
      5. 5Marker 5: Records, where findings and notes collect.
      6. 6Marker 6: Settings.
      7. 7Marker 7: Your account menu. See Your account menu.

      Changing the proxy port#

      PentAgent listens on port 8088 by default. If another program already uses it, open Settings › Proxy & gateway and change Listen port under Listener defaults. Check port tells you whether the new port is free.

      If something doesn’t work#

      What you seeWhat to do
      No lab browser foundRestart PentAgent while connected to the internet so first-launch setup can finish downloading the lab browser.
      The proxy won't startAnother program may be using port 8088. Pick a different Listen port in Settings › Proxy & gateway.
      Pages show a certificate warningMake sure you're browsing in the lab window, which trusts the PentAgent CA certificate automatically.
      Nothing appears in HTTP historyCheck the proxy button reads Proxy Active and that you're browsing in the lab window, not your everyday browser.
