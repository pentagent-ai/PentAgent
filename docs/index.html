      PentAgent documentation

      PentAgent is a desktop workbench for testing web apps. It captures traffic through a local proxy, helps you understand what it sees, and only runs tests when you say so. These guides walk through every part of it.

      New here? Start with Getting started. It takes you from download to your first captured request in a few minutes.

      Getting started

      Getting started overviewThe short path from download to your first captured request.InstallDownload the pilot build, start it, and open PentAgent.Sign inSign in with GitHub and what happens while your access is being approved.Welcome screenThe two quick checkboxes you see once, before the app opens.First runCreate a project, start the proxy, and capture your first request.

      Capture

      Proxy & InterceptStart capturing, then pause, edit, forward or drop requests with Intercept.HTTP historyBrowse, search and filter everything the proxy has captured.WebSocketsSee WebSocket frames captured through the proxy.Match / ReplaceRewrite requests and responses automatically as they pass through.ImportBring in HAR or XML captures, and move whole projects between machines.

      Test

      RepeaterEdit a request by hand, send it again, and compare what comes back.FuzzerSend one request many times, swapping in a list of values at the places you mark.ScannerRun a passive audit on captured traffic and review the issues it finds.Target & scopeSet which hosts are in scope, and browse the sitemap of what you've captured.OrganizerKeep interesting requests in collections with notes, tags and leads.DecoderEncode, decode and hash values, or chain several steps together.ComparerDiff two requests or responses side by side.SequencerCapture session tokens and check whether they look random.CollaboratorGenerate out-of-band payloads and watch HTTP and DNS callbacks.InspectorSee params, cookies and headers for the message you have selected.

      Project

      DashboardSee capture health, findings, scans and recent evidence for the current project.SitemapThe Target sitemap and the UI Map built from the lab browser.KitsBrowse the attack library and build campaign kits from Plan threads.

      Findings

      RecordsThe engagement report in Markdown, with chapters you or the model can maintain.

      AI

      AskAsk questions about traffic, scope and coverage in the AI Assistant.PlanWrite an attack plan the agent can follow.AgentRun an approved plan with live requests that ask for your approval.ContextAttach recon notes and see the request selected for the assistant.Approvals & stopApprove live requests, stop runs, Explore toggles and spend caps.

      Settings

      GeneralTheme, API health, embeddings and lab browser overview.AI modelsProviders, Explore toggles, approvals batch mode and spend caps.Proxy & gatewayListener defaults, lab browser, CA certificate and proxy options.ProjectScope, rename, filter defaults, upstream proxy and delete for the active project.CollaboratorOut-of-band listener status and environment variables.Lab browserHow lab Chromium, the capture extension and proxy modes work.

      Reference

      ShortcutsKeyboard shortcuts for the workbench, Repeater and Fuzzer.TroubleshootingFixes for common install, sign-in, proxy and capture problems.FAQShort answers to common questions about the pilot.

      Testing responsibly

      Only test apps you own or have permission to test. A practice app running on your own machine is a great place to start.
