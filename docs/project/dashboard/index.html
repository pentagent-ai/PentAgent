      Dashboard

      See capture health, findings, scans and recent evidence for the current project.

      The Dashboard is the overview for the current project. Open it from the left menu under Project. With no project selected it says Open or create a project to see capture health, findings, and recent evidence.

      What you see#

      CardWhat it shows
      CaptureProxy status, transaction count and last seen. Open history / See history jumps to HTTP history. If the proxy is off, it points you to start it.
      UnderstandingHosts, pages and tech from the Target map. Open Target → opens the sitemap.
      FindingsIssues from passive scans. Open Scanner, or Run a passive scan / Launch passive scan when empty.
      TestingScan runs and other tasks. New scan / Start a passive scan starts one. Double-click a task to rename it.
      Recent evidenceJump points to transactions linked from scan issues.

      Tip

      Background imports and kit builds also show progress here under other tasks.
