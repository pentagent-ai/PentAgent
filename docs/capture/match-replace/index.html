      Match / Replace

      Rewrite requests and responses automatically as they pass through.

      Proxy › Match / Replace rules change traffic automatically. They run while the listener captures, before anything reaches Intercept or HTTP history. Use them to swap a header, flip a flag in a URL, or tidy up a response body without stopping each request by hand.

      1. 1Marker 1: The form for a new rule.
      2. 2Marker 2: Your rules. Each one has an on box and a Delete button.

      Add a rule#

      1. Name it

        Give the rule a short Name so you can spot it later.

      2. Pick where it applies

        Choose Request, Response or Both, then the part to look in.

      3. Fill in Match and Replace

        Leave Replace empty to remove what matched. Tick Regex to use a regular expression.

      4. Click Add rule

        The rule is on straight away.
      WhereLooks in
      AnyThe URL, headers and body.
      URLThe request URL only.
      HeadersThe header lines.
      BodyThe message body.

      In the list, a rule shows as match → replace with where it applies, for example request/headers · regex. An empty replace shows as ∅.

      Turn a rule off or delete it#

      Untick on to pause a rule without losing it. Delete removes it for good.

      Tip

      Rules belong to the current project, so each project can have its own set.

      Note

      Rules only change traffic captured from now on. Requests already in HTTP history stay as they were.
