      HTTP history

      Browse, search and filter everything the proxy has captured.

      Proxy › HTTP history lists every request and response that went through the listener for the current project, newest first. Rows appear live while you browse in the lab window.

      The list#

      1. 1Marker 1: The toolbar: HTTP / HTTPS chips, a Domain picker, Search requests…, the Filter button and the count of matching rows.
      2. 2Marker 2: The table. By default it shows #, Method, URL, Status code, Length, Time and Source.
      3. 3Marker 3: The selected exchange, with the request on one side and the response on the other.

      Long histories load in pages. The line above the table reads Showing 50 of 1,240 (newest first) or similar. Click Load more rows to fetch more.

      Look at a request#

      Click a row to open it below the table. Each side has pretty, raw and hex views. From here you can:

      • Click the Send to Repeater arrow to open the request in Repeater and switch to it.
      • Right-click the row or the message for more actions, like sending it to other tools.

      The Inspector panel on the right breaks the selected message into params, cookies and headers.

      Search and filter#

      Type in Search requests… to narrow the list. A small × clears it. The HTTP and HTTPS chips and the Domain picker are quick toggles. Click a chip again to turn it off.

      The filter dialog#

      Click Filter for everything else.

      1. 1Marker 1: Quick filters: the same protocol and domain choices as the toolbar.
      2. 2Marker 2: History filters: host, method, status, status class, path/URL search, and the hide options below.
      3. 3Marker 3: Columns: pick which columns the table shows.
      FilterDefault
      Hide staticOn. Hides CSS, scripts, images and fonts.
      Hide browser noiseOn. Hides browser telemetry, updates and connectivity checks.
      Hide CDNOn. Hides common CDN hosts.
      All hosts / In scope / Out of scopeIn scope, unless your project options say otherwise.
      Legacy extension trafficOff. Only for rows captured by an older browser extension.

      Seeing fewer rows than you expect?

      History starts filtered to in-scope hosts. If your project has no scope yet, or the site you’re browsing isn’t in it, switch the scope filter to All hosts, or add the host on the Target tab.

      Filtering to one host#

      Some views, like the insights strip under the history, can narrow the list to one host. A Host: demo.local line then appears above the toolbar. Click clear to remove it.

      Clear history#

      In the filter dialog, Clear history deletes every captured request for this project. PentAgent asks you to confirm first, because this can’t be undone. Refresh reloads the list.

      When the list is empty#

      With no captures yet, the sub-tab shows the Get your first capture steps. See First run, then browse your target in the lab window.
