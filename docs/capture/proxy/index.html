      Proxy & Intercept

      Start capturing, then pause, edit, forward or drop requests with Intercept.

      The Proxy tab is where traffic from the lab browser comes in. It has five sub-tabs: Intercept, HTTP history, WebSockets, Match / Replace and Import. This page covers the listener and the Intercept sub-tab.

      Start and stop the listener#

      PentAgent captures through a local listener, 127.0.0.1:8088 by default. You can start it from any of these places:

      • The proxy button in the top bar. It reads Proxy Off until the listener runs.
      • Start proxy in the Get your first capture steps.
      • Open lab browser, which starts the listener for you if it isn’t running.

      To stop, click the proxy button again (its tooltip reads Stop proxy (127.0.0.1:8088)), use the ■ next to Lab at the bottom of the left menu, or Stop listener in Settings › Proxy & gateway. Once it stops, the lab browser shows No internet until you open it again.

      Note

      The listener belongs to one project at a time. If another project is using it, the Proxy tab says Listener owned by another project. Opening the lab browser or turning on Intercept here moves it to this project.

      Intercept#

      Intercept pauses matching traffic in the lab browser so you can look at it, change it, and then send it on or drop it. While Intercept is off, traffic flows normally and shows up in HTTP history.

      1. 1Marker 1: The Intercept is off / Intercept is on switch.
      2. 2Marker 2: What to pause, and what to let through without stopping.
      3. 3Marker 3: Intercept match rules for finer control.

      Turn Intercept on#

      1. Click Intercept is off

        It turns into Intercept is on. If the listener isn’t capturing yet, PentAgent starts it and opens the lab browser if needed. Your everyday browser isn’t affected.

      2. Reload your target in the lab window

        The page waits while its requests are held. Static files like CSS, scripts, images and fonts are skipped by default.

      Turning Intercept off again forwards everything still in the queue, so nothing is left hanging.

      Choose what gets paused#

      OptionWhat it does
      Intercept requestsPause requests on their way to the site.
      Intercept responsesPause responses on their way back to the browser.
      Don't intercept static (css/js/images/fonts)Let page assets through without stopping.
      Don't intercept browser noiseSkip browser telemetry, updates, connectivity checks and prefetch.
      In-scope onlyOnly pause traffic to hosts in your project’s scope. On unless you turn it off.
      Intercept WebSocket framesPause WebSocket messages as well as HTTP.

      Intercept match rules#

      Rules sit on top of the options above. Click Add rule, pick Include or Exclude, then choose what to match on: Host, Method, Path, URL, Header or Protocol (http or websocket). Each rule has its own on/off box.

      • If any include rule is on, traffic has to match at least one include to be paused.
      • An exclude rule always wins over an include.

      Work through held items#

      1. 1Marker 1: The queue, with Forward all and Drop all above it. The sub-tab shows a count, like Intercept (2).
      2. 2Marker 2: Actions for the selected item.
      3. 3Marker 3: The editor. Change the method, URL, headers or body. For a response, you can change the status, headers and body.
      ActionWhat happens
      Forward FSends the item on, with any edits you made.
      Forward & next Ctrl+FSends it on and stays ready to pause the next matching item.
      Drop DThrows the item away. The browser never gets it.

      Tip

      The keyboard shortcuts work when the Intercept panel has focus. Click anywhere inside it first.

      If something doesn’t work#

      What you seeWhat to try
      Intercept is on but lab Chromium is not runningOpen the lab browser (Lab in the left menu, or Settings › Proxy & gateway), then reload the target there.
      Nothing gets pausedCheck that you’re browsing in the lab window, and that the host is in scope or In-scope only is off.
      Pages stall after you leave Intercept onTurn Intercept off. The queue is forwarded automatically.
